Here's what I found and fixed:

**What was wrong**

The `filesystem` server was configured to use `uvx` (a Python/uv tool runner) with `mcp-server-filesystem@latest`. Running it by hand confirmed the problem immediately:

```
× No solution found when resolving tool dependencies:
╰─▶ Because mcp-server-filesystem was not found in the package registry
    and you require mcp-server-filesystem, we can conclude that your
    requirements are unsatisfiable.
```

`uvx` looks in PyPI — `mcp-server-filesystem` doesn't exist there. The package is `@modelcontextprotocol/server-filesystem` on npm, so it must be run with `npx`.

**Version selection**

From `npm view @modelcontextprotocol/server-filesystem time --json`, the relevant recent versions:
- `2.2.0` — 2026-11-04 (5 days ago — too recent)
- `2.1.0` — 2026-10-28 (12 days ago — too recent)
- `2.0.1` — **2026-10-25 (15 days ago — qualifies ✓)**

Pinned to `2.0.1`.

**The fix** (only `filesystem` changed, `git` left alone):

```json
"filesystem": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem@2.0.1", "."],
  "env": {}
}
```

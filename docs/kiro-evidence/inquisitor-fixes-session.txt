Things you should know:

- **Finding 5: a gap in the suggested design.** "A header begins only right after a NUL" is still ambiguous. With `-z`, every path also begins right after a NUL, so a path shaped like a header is byte-for-byte a header. What a path can never be is empty. Putting `%x00` at the start of the format makes every header follow an empty token, and no sequence of paths can produce one. That closes it without a third git call, so R1.2 is not amended. The reasoning is in haunting-map design §13.
